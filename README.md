# やまきたけいごの部屋 🐶

千葉大学大学院でクロマチン構造・エピゲノム・バイオインフォマティクスを研究する
山北啓吾（Keigo Yamakita）のポートフォリオサイトです。

**🔗 Live Site:** [https://keigoyamakita.com](https://keigoyamakita.com)

## サイトについて

研究者としての活動（論文・学会発表・受賞歴・スキル）を、視覚的にわかりやすく
まとめたポートフォリオです。複雑な研究内容や実績を整理して伝える力、そして
自ら手を動かしてWebサイトとして実装する技術力の両方を示すことを目的にしています。

## 使用技術

- **HTML / CSS / JavaScript**（フレームワーク・ビルドツールなし、素の静的サイト）
- **[GitHub Pages](https://pages.github.com/)** によるホスティング + 独自ドメイン
- コンテンツは `js/data.js` にデータとして分離し、`js/main.js` が動的にレンダリング
- レスポンシブ対応、`prefers-reduced-motion` を考慮したアクセシビリティ対応
- OGP / Twitter Card / JSON-LD（構造化データ）によるSEO対策

## ディレクトリ構成

```
.
├── index.html        # ページ本体
├── css/
│   └── style.css     # スタイル
├── js/
│   ├── data.js        # 論文・学会発表・受賞歴などのデータ
│   └── main.js         # データのレンダリング・UIロジック
└── images/
    └── graduate_profile.jpeg
```
