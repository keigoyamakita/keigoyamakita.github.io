1日1本 — 新着論文を1日1本だけ届けるアプリ

登録したキーワードに合う新着論文の要旨を、PubMed と bioRxiv から1日1本だけ届けます。論文を読む習慣を無理なく続けるためのアプリです。

iOSPubMedbioRxiv論文研究
App Store で見る ↗プライバシーポリシーお問い合わせ

主な機能

キーワード登録

自分の研究分野のキーワードを登録すると、それに合う新着論文を選んで届けます。

1日1本の通知

指定した時刻に、その日の1本を通知で知らせます。

差し替え

「合わない」を選ぶと別の論文に差し替えます。同じ論文が重ねて届くことはありません。

履歴と翻訳

届いた論文は履歴に残ります。要旨は iOS 標準の翻訳機能で翻訳できます。

データの扱い

アカウント登録は不要で、キーワードや履歴は端末内にのみ保存されます。論文の取得は PubMed（NCBI E-utilities）と bioRxiv API へ直接通信します。詳しくはプライバシーポリシーをご覧ください。
