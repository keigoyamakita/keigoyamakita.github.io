No Book No Life（仮称）

iPhone向け読書記録アプリ（開発中）
提供者：山北啓吾（個人）

読んだ本を記録し、星評価と「何が楽しかったか」をもとに、次に読む本を理由付きで提案するアプリです。現在開発中で、App Storeでは公開していません。

主な機能（予定）

  • 書名・著者名で本を検索して本棚に登録
  • 星1〜5の評価、感想、「楽しかった点」タグの記録
  • 読みたい・読書中・読了の管理と本棚の並べ替え
  • 高評価の本をもとにした関連本の提案（共通する著者・ジャンル・キーワードを理由として表示）

データの取り扱い

アカウント登録は不要です。読書記録は端末内に保存されます。詳しくはプライバシーポリシーをご覧ください。

書誌データの出典

本の情報（書名・著者・書影・内容紹介・ジャンル・レビュー）は、楽天ブックス書籍検索API および Google Books API から取得しています。
